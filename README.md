# EngineerAI

EngineerAI is a **Personal AI Engineering Company** — a lifelong engineering partner designed to transform ideas, sketches, photos, drawings, and engineering requirements into manufacturable engineering solutions, learning from every project through a Knowledge Vault.

This repository is under **active foundational development** (Sprint 1: repository scaffolding and core infrastructure). No application functionality exists yet.

See [`docs/vision.md`](docs/vision.md) for the project's full mission statement, long-term vision, core principles, department descriptions, Knowledge Vault philosophy, future roadmap, and major architecture decisions log.

See [`docs/roadmap.md`](docs/roadmap.md) for the sprint-by-sprint development roadmap.
